# 주문 취소 사유 기능 명세

> 작성일: 2025-12-19
> 백엔드 작업 완료, 프론트엔드 작업 필요

---

## 개요

관리자가 발송관리에서 주문을 취소할 때 취소 사유를 입력하고, 고객이 주문관리에서 취소된 주문을 조회할 때 해당 사유를 확인할 수 있는 기능입니다.

### 요구사항 요약

1. **발송관리** (`/send/general/detail/:id`, `/send/ssg/detail/:id`)
   - 주문취소 버튼 클릭 시 취소사유 입력 모달 표시
   - 취소사유 입력 후 저장

2. **주문관리** (`/order/general/detail/:id`, `/order/ssg/detail/:id`)
   - 취소된 주문 접속 시 취소사유 모달 표시
   - "다시 보지 않기" 체크박스 옵션 (localStorage 활용)
   - 취소된 주문도 수정/임시저장/발송요청 가능

## API 변경사항

### 1. 주문 취소 API

**Endpoint:** `POST /order/delivery-cancel`

**Request Body:**
```json
{
  "id": 123,
  "cancelReason": "고객 요청으로 인한 취소"
}
```

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| id | number | O | 주문 ID |
| cancelReason | string | O | 취소 사유 (최대 1000자) |

**Response:** 기존과 동일

---

### 2. 주문 상세 조회 API

**Endpoint:** `GET /order/detail/:id`

**Response Body (추가된 필드):**
```json
{
  "id": 123,
  "status": "DELIVERY_CANCEL",
  "eventName": "이벤트명",
  ...
  "cancelReason": "고객 요청으로 인한 취소",
  "canceledAt": "2025-12-19T14:30:00"
}
```

| 필드 | 타입 | 설명 |
|------|------|------|
| cancelReason | string \| null | 취소 사유 (취소되지 않은 주문은 null) |
| canceledAt | string \| null | 취소 일시 (yyyy-MM-ddTHH:mm:ss 형식) |

---

### 3. 임시저장 수정 API

**Endpoint:** `PUT /order/temp`

**변경사항:**
- 기존: `TEMP` 상태만 수정 가능
- 변경: `TEMP` 또는 `DELIVERY_CANCEL` 상태 수정 가능
- `DELIVERY_CANCEL` 상태의 주문을 수정하면:
  - 상태가 자동으로 `TEMP`로 변경
  - `cancelReason`, `canceledAt`이 null로 초기화

### 1. 발송관리 - 취소사유 입력 모달

**파일:** `SendGeneralDetailPage.tsx`, `SendSSGDetailPage.tsx`

**현재 코드:**
```typescript
const handleOrderCancel = useCallback(async () => {
  if (detailData?.id && confirm('주문을 취소하시겠습니까?')) {
    await cancelOrder(detailData.id)
    // ...
  }
}, [detailData?.id, cancelOrder, queryClient])
```

**변경 필요:**
1. `confirm()` 대신 취소사유 입력 모달 표시
2. 모달에서 취소사유 입력 후 API 호출

**모달 UI 예시:**

### 2. 주문관리 - 취소사유 확인 모달

**파일:** `OrderGeneralDetailPage.tsx`, `OrderSSGDetailPage.tsx`

**구현 내용:**
1. 페이지 로드 시 `status === 'DELIVERY_CANCEL'`이면 모달 표시
2. 모달에 `cancelReason`, `canceledAt` 표시
3. "다시 보지 않기" 체크박스
4. localStorage로 사용자 설정 저장

**모달 UI 예시:**
```
┌─────────────────────────────────────┐
│  주문 취소 안내                       │
├─────────────────────────────────────┤
│                                      │
│  이 주문은 취소되었습니다.             │
│                                      │
│  취소 일시: 2025-12-19 14:30:00      │
│                                      │
│  취소 사유:                           │
│  ┌─────────────────────────────────┐│
│  │ 고객 요청으로 인한 취소           ││
│  └─────────────────────────────────┘│
│                                      │
│  ☐ 이 주문에 대해 다시 보지 않기      │
│                                      │
│              [확인]                   │
└─────────────────────────────────────┘
```

**localStorage 키 예시:**
```typescript
// 주문별로 "다시 보지 않기" 설정 저장
const CANCEL_MODAL_DISMISSED_KEY = 'cancelModalDismissed'

// 저장
localStorage.setItem(CANCEL_MODAL_DISMISSED_KEY, JSON.stringify({
  ...existing,
  [orderId]: true
}))

// 확인
const dismissed = JSON.parse(localStorage.getItem(CANCEL_MODAL_DISMISSED_KEY) || '{}')
if (!dismissed[orderId] && detailData?.status === 'DELIVERY_CANCEL') {
  // 모달 표시
}
```

### 3. 주문관리 - 취소된 주문 수정 가능

**파일:** `OrderGeneralDetailPage.tsx`, `OrderSSGDetailPage.tsx`

**현재 코드:**
```typescript
// 수정 가능 여부 체크
isEdit={detailData?.status === 'TEMP' || detailData?.status === null}

// 버튼 비활성화
disabled={detailData?.status !== 'TEMP'}
```

**변경 필요:**
```typescript
// 수정 가능 여부 체크
const isEditable = detailData?.status === 'TEMP' ||
                   detailData?.status === 'DELIVERY_CANCEL' ||
                   detailData?.status === null

isEdit={isEditable}

// 버튼 비활성화
disabled={!isEditable}
```
