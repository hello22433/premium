# 프론트엔드 연동 요청 — 상품찾기 팝업 유효기간 기본값 자동 적용

## 배경

일반 쿠폰 주문 등록 화면에서 담당자 선택 후 상품추가 팝업을 열면
유효기간 필터 기본값이 권한자 기준 항상 60일 고정이었습니다.

담당자별 연동상품 유효기간이 다를 수 있어,
해당 담당자의 연동상품 유효기간 평균을 계산하는 API를 신규 추가했습니다.
이 값을 활용해 팝업의 초기 유효기간 필터를 자동으로 맞춰주는 연동을 요청합니다.

---

## 변경 흐름

```
[기존]
담당자 선택 → 상품추가 클릭 → 팝업 오픈
→ 팝업: 유효기간 필터 기본값 60일로 고정 → /product/list 호출

[변경]
담당자 선택
  → (신규) GET /product/link/average-expire-day?headPersonUserId={id}
  → 응답값 기준으로 초기 유효기간 범위 결정
→ 상품추가 클릭 → 팝업 오픈 (결정된 범위 전달)
→ 팝업: 전달받은 범위로 초기 필터 적용 → /product/list 호출
```

담당자가 선택되지 않은 경우(자사 주문)에는 신규 API 호출 없이 기존 동작을 유지합니다.

---

## 신규 API 명세

### `GET /product/link/average-expire-day`

담당자(headPersonUserId)의 ACTIVE 연동 이벤트에 매핑된 상품들의
유효기간 평균을 반환합니다.

**Request**

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `headPersonUserId` | number | Y | 담당자 user.id |

**Response**

```json
{ "averageExpireDay": 28.4 }
```

```json
{ "averageExpireDay": null }
```

- `averageExpireDay` — 유효기간 평균(일, float). ACTIVE 연동상품이 없으면 `null`
- 유효기간 기준: 상품의 `galaxia_duration`(GALAXIA 전용) 우선, 없으면 `expire_day` 사용
- 소프트딜리트된 이벤트·매핑·상품, 미사용(UNUSED) 상품은 모두 집계에서 제외됩니다

---

## 평균값 → 유효기간 범위 매핑 가이드

| `averageExpireDay` | 권장 초기 범위 |
|--------------------|---------------|
| `null` | 기존 기본값 유지 |
| 45일 이하 | 30일 전후 |
| 45일 초과 | 60일 전후 |

임계값 45는 30일·60일 프리셋의 중간값입니다.
프론트 측 로직에서 상수로 관리해 주시면 추후 조정이 용이합니다.

---

## 동작 시나리오

| 상황 | 팝업 초기 유효기간 필터 |
|------|------------------------|
| 담당자 미선택 (자사 주문) | 기존과 동일 |
| 담당자 선택, 연동상품 없음 (`null`) | 기존과 동일 |
| 담당자 선택, 평균 28일 | 30일 전후 범위 |
| 담당자 선택, 평균 58일 | 60일 전후 범위 |
| 사용자가 팝업 안에서 직접 변경 | 사용자 선택 우선 |
